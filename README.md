# Colour CRT Monitor for a Retro Luggable Computer

I'm in the process of assembling a luggable Apple ][ clone system.  This is the colour monitor part of the project.

This monitor started out as a SKYTEK brand SCT-1024 portable colour television from May of 1988 that I picked up from an auction site.  The video baseband and CRT driver section is built around a Panasonic 150CHB22 picture tube driven by a Toshiba TA7698AP video-chroma-deflection system all-in-one chip.  I think those picture tubes were quite common in small televisions of this type, and the all-in-one chip is easy to find, so this project might be useful for others looking for a way to make a small DIY CRT colour monitor from salvaged parts.
